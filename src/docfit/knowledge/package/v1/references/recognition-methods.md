# 识别方法

## 建立任务证据清单

先记录每份材料的来源、日期、适用范围和文件角色。把当前学校事实保留在任务上下文，
不要写回产品 Knowledge。对于缺少来源或适用范围不明的材料，标记不确定性。

## 识别结构

结合标题文字、段落层级、样式、分页关系、编号序列、表格边界以及前后对象关系识别
文档单元。不要仅凭样式名称或视觉相似度决定语义角色。遇到模板占位内容时，应区分
“用于说明结构的示例”与“交付物必须保留的固定内容”。

## 识别格式要求

从要求文件提取明确声明，再用模板结构和渲染结果补充可观察证据。把单位、作用对象、
继承范围、例外条件和优先级一起记录；缺少这些上下文的数值不能独立成为操作参数。

## 保留可追溯性

每条任务规则应能指回当前任务中的具体证据位置。无法追溯或只由模型猜测得到的结论，
必须保持为假设并在执行前请求确认或通过更多证据验证。
