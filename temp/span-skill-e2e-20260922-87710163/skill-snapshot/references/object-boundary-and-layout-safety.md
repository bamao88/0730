# 对象边界与布局安全

## 用途

帮助 Agent 识别文本之外的学校布局责任，例如空白、图片、表单框架和分页关系。Agent 判断哪些内容
与空间应保留，底层对象选择和编辑安全由宿主处理。

## 触发条件

- 目标对象附近有表格、图片、文本框、页眉页脚、分节、分页、字段、书签、脚注或批注。
- 固定标签、学生值和说明在同一行，布局关系影响它们的含义。
- 删除父对象会影响子对象，或包装段同时承载布局和内容。
- 视觉位置、空白、装饰线、印章位或表单框架本身具有学校责任。

## 核心判断规则

- 按可见文本与布局关系表达最小必要的语义范围；文字同段或紧密相邻不限制语义拆分。
- 布局对象可能没有学生内容，但仍承担视觉或空间责任；不要因为无文字就删除。
- 位于两个已有完整内容承载的可见块之间、只承担段间距或留白的空白 entry，用无字段的固定或样式责任保留；它不是正文代表成员，不绑定 `body_structure` 或其它近似字段。
- 同一区域既有应清理的说明又有应保留的内容时，分别表达责任及预期布局。
- 历史分页缓存、旧截图或旧检查结果不能决定当前语义。
- 编辑失败由宿主处理；反馈若揭示原文含义或布局关系判断有误，再修正语义结论。
- 任何影响布局的语义处理都要写清相邻结构与页面预期；后续复核由宿主完成。

### 空白是填写位置，还是布局

相邻标签和布局确认输入中的空白就是独立值位置时，该空白可承担填写责任，包括输入明确提供的
空文本。必须使用已提供的位置，不虚构新的空位；没有填写依据的空白仍是无字段布局。

同一视觉填写区从标签后的留白延续到相邻空白片段时，只建立一个足以承载完整值的接口，其余空白
保留布局，不为预留换行重复绑定字段。另一处确实要求同一个完整值再次出现时，才是分别填写的
真实镜像；详细字段条件见 [Registry 与接口绑定](registry-interface-binding.md)。

| 当前布局证据 | 判断与填写后的效果 |
| --- | --- |
| 项目名称栏的值位置后还有一行空白，只供同一名称换行 | 在已确认的值位置建立一个填写接口；续行空白无字段，最终名称只填写一次。 |
| 封面与摘要页各有独立的项目名称位置，均要求显示同一名称 | 两处分别建立接口；最终每个位置各显示一次名称。 |

### 真实留白与间距说明

`style_only` 可以表达真实空白的布局责任，也可以表达说明文字所描述的布局要求。它们的字面
保留方式不同：真实空白保留其空间作用；“空一行/空若干行”或已明示表示间距的符号，保留要求，
说明文字本身不是最终固定正文。不能仅凭 `□` 的形状做决定，复选框和正式符号仍按实际用途判断。

下表引号只用于展示原文边界，不属于原文；假想显示效果不是输出 parts。

| 上下文与原文 | 按原文顺序的 parts | 最终显示与布局预期 |
| --- | --- | --- |
| 人工签名行，原文 `  签名：______  `，两侧空白用于定位 | `  ` → style_only；`签名：______` → manual_region；`  ` → style_only | 保留两侧空间与中间人工签名位置，不添加自动填写字段。 |
| 段间有说明 `空三行`，学校明确要求它表示留白 | `空三行` → style_only | 保留三行间距要求，不显示“空三行”三个字。 |
| 学校明确声明 `□` 表示字宽，原文 `□□摘要` | `□□` → style_only；`摘要` → fixed_label | 保留标题前的字宽要求和“摘要”，不显示方框符号。 |
| 表单让使用者勾选，原文 `□同意 □不同意` | `□同意 □不同意` → manual_region | 保留两项选择及复选框，不把方框转换成留白或因未勾选而删除。 |

签名或日期等人工内容前后的真实空白可单独拆成 `style_only` parts，中间可见内容保持
`manual_region`。原文中的前导或尾随空白、普通空格、不换行空格及其它空白不能替换或归一化；
不以视觉宽度猜测字符。字符传输有误时依据宿主反馈修正原文，不能因此改变字段或人工责任。

## 反例

- 删除一个看似空白的段落，却同时删除图片锚点、分页或页眉页脚边界。
- 把标题、正文或关键词等完整承载之间的排版空行绑定为正文字段，只因为词表提供了正文段落字段。
- 把表格边框当装饰清理，实际破坏学校表单骨架。
- 只判断示例值，遗漏同一单元格里相邻说明和其它填写位置的责任。
- 用 `lastRenderedPageBreak` 或旧截图单独判断当前逻辑分页。

## 不负责事项

- 不定义 OOXML 变更算法、工具参数或权限策略。
- 不替代完成阶段的最终全页视觉复核。
- 不决定学生内容最终如何运输对象；这里只判断模板提取阶段的内容与布局责任。
