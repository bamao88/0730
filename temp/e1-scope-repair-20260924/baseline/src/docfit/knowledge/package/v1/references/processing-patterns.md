# 通用处理模式

## 检查—计划—修改—验证

1. 检查源文档结构、可见页面和当前任务证据。
2. 把确定规则、不确定项、冲突和受影响对象整理成任务级计划。
3. 用范围最小、可追溯的操作修改副本，保留源文档只读。
4. 重新检查结构并渲染页面，确认修改满足任务规则且未引入回归。

## 语义判断与确定性执行分离

Agent 负责解释证据、识别对象和处理歧义；Tool 负责按当前任务已经确认的参数执行检查、
修改和渲染。Tool 不应从长期 Knowledge 猜测学校参数，Knowledge 也不保存 Tool 私有
定位信息。

## 失败与升级

发现缺失证据、无法解释的冲突或高风险结构变化时，停止相关修改并保留诊断信息。
优先请求用户确认或补充任务证据。不能通过重复尝试把不确定结论伪装成已经验证的事实。
