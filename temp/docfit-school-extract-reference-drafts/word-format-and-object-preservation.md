# Word 有效格式与对象完整性

> 状态：Temp 草稿。用于未来论文模板提取 Skill 的按需 Reference。本文件暂时合并两个高频风险域；未来材料明显增长时可以拆成两个 Reference。

## 当前任务应留下什么

- 关键语义角色逐属性计算后的最终有效格式；
- 与学校要求冲突或被直接格式覆盖的属性；
- 图、表、公式、引用、脚注和浮动对象的成员关系；
- 每次删除、移动或清理需要保护的对象与 package 关系；
- Word 保存后有效格式和对象闭包的复验结果。

## 何时读取

在以下情况读取本文件：

- 样式名正确但 Word 显示仍不正确；
- 同一段中中文、西文、公式或超链接格式不一致；
- 删除题注、空段或表格边框时可能影响图片、公式或表格；
- 处理浮动对象、OMML、图表题注、脚注、书签或批注；
- XML/包校验通过，但视觉结果、关系或 Word 行为异常。

## 第一部分：有效格式

### 1. 样式定义不是最终格式

Word 最终显示可能同时受到以下层级影响：

1. 文档默认值；
2. 主题字体和主题颜色；
3. `basedOn` 样式继承；
4. 当前命名样式；
5. 编号和列表级别属性；
6. 段落直接格式；
7. Run 直接格式；
8. 表格、行和单元格直接属性；
9. 分节、页眉页脚和对象容器属性。

观察和验收都应针对最终有效值。设置目标样式后，旧直接格式仍可能覆盖它。

### 2. 逐属性处理冲突

不要为整个样式选择一个“赢家”。分别比较：

- 中西文字体；
- 字号；
- 粗体、斜体和颜色；
- 字符间距、缩放和位置；
- 对齐；
- 左右和首行缩进；
- 段前、段后和行距；
- 与下段同页、段中不分页和另页开始；
- 编号和大纲级别；
- 表格边框、宽度、单元格边距和行高。

每个属性保留来源和适用范围。学校说明可以定义目标值，模板有效显示可以说明实现方式；两者冲突时不能静默把整套样式覆盖掉。

### 3. 常见有效格式陷阱

- `jc=center` 存在，但继承的左缩进让对象视觉上偏移；
- 样式字体正确，Run 上仍保留旧字体或粗体；
- “黑体”被错误理解为还要额外加粗；
- 目录缓存 Run 的直接格式遮住错误 TOC 样式；
- 只设置三线表样式，没有删除 `tblBorders`、`tblPrEx` 或 `tcBorders` 覆盖；
- 只清除段落样式，没有清除字符间距、缩放和位置；
- 固定行距对普通正文正确，却裁切公式或高对象。

### 4. 显示宽度不是字符串长度

封面固定行、下划线和表格题名容量与字形、东亚字符宽度、字体和单元格宽度有关。不能用 Python `len()` 直接决定换行，更不能通过任意缩小字号掩盖布局错误。

容量阈值必须来自当前模板结构和 Word 实测；它属于任务证据，不是通用常量。

## 第二部分：复合对象完整性

### 5. 先识别复合对象，再修改成员

以下对象通常不能作为互不相关的文本段落处理：

| 复合对象 | 常见成员 | 主要风险 |
|---|---|---|
| 图片单元 | 图片、锚点、中文题注、英文题注、编号、交叉引用目标 | 删除题注时误删图片，或题注与图片跨页 |
| 表格单元 | 表题、表格、英文表题、注释、来源、包装段 | 误删数据、边框覆盖、包装段产生空白页 |
| 公式单元 | OMML、编号、制表位或对齐结构、前后段落 | 转成文本/图片、固定行距裁切 |
| 引用单元 | 可见引文、字段或超链接、书签、参考文献条目 | 可见编号存在但目标失效 |
| 脚注单元 | 正文标记、脚注部件、关系和编号 | 标记与正文定义不平衡 |
| 条件表单 | 固定标题、字段、签字区、分节和分页 | 只删文字留下空白页 |
| 浮动对象 | 锚点段、Drawing、图片关系、环绕和位置 | 移动锚点导致对象丢失或遮挡 |

复合对象的身份来自成员关系、顺序、邻接和机制，不只来自样式名或文本前缀。

### 6. 修改前检查对象闭包

在删除、移动、清空或重新编号前检查：

- 目标段是否同时含文字和 Drawing；
- 题注是否有中文、英文、编号和引用目标；
- 表格后空段是否承载书签、分页、批注或 Word 包装职责；
- OMML 是否与编号位于同段或相邻结构；
- 浮动对象的锚点和 relationship 是否随对象迁移；
- 删除一个条件内容是否需要删除整个分节；
- 批注、修订、脚注和书签范围是否成对。

未知可见对象原位保留并报告，不能因为当前库不支持就从正文中消失。

### 7. 图表对象的学校差异

通用 Skill 只固定判断方法：识别成员、顺序、语言、编号和附着关系。以下内容必须由当前学校证据决定：

- 图题在图上方还是下方；
- 表题和英文表题的顺序；
- 是否需要双语题注；
- 图表编号是否按章重置；
- 注释和来源是否必需；
- 表格采用三线表还是其他形式。

## 8. 真实案例

### 案例 A：假居中

湖南农业大学模板中出现 `jc=center`，但继承缩进仍影响可见位置。只检查对齐属性会误判通过。应同时检查有效缩进和 Word 渲染位置。

### 案例 B：设置样式后旧 Run 仍覆盖

早期模板把正文和标题套入目标命名样式，但原学生稿的直接字体、粗体和字符间距仍存在。最终需要按允许范围清理非语义覆盖，并比较有效值而不是样式 ID。

### 案例 C：图片与文字在同一段

南京农业大学学生稿中，浮动图片的锚点和可见说明文字可能共处一个段落。整段删除说明会同时删除图片。应先拆分或迁移对象结构，再清理文字。

### 案例 D：中英文题注作为原子媒体单元

南京农业大学三份学生稿要求识别“图片 → 中文图题 → 英文图题”和“中文表题 → 表格 → 英文表题”，再统一编号、顺序和分页。仅给题注段设置 `keepNext` 不能证明整个对象不会拆散。

### 案例 E：英文题注删除不能连带删除图片

北京大学候选 r02 认为最终只保留中文图表题注。即便该学校规则最终获批，删除英文题注前仍必须检查它是否与图片、表格或字段共段，必要时先迁移受保护成员。

### 案例 F：三线表样式被直接边框覆盖

北京大学候选中，仅指定学校三线表样式后，学生表格的表级、行级和单元格网格线会在 Word 保存时恢复。应在明确限定的数据表范围内清理直接边框；封面布局表不能按同一规则处理。

### 案例 G：公式被固定行框裁切

南京农业大学 student-002 的 OMML 公式被普通正文固定 20 磅行距裁切。修复保留 OMML，不转图片，公式段使用适合对象高度的行距策略。

### 案例 H：窄范围空段清理

北京大学候选 r02 只清理“中文表题与紧邻表格之间、且不承载任何结构或关系”的纯布局空段。该规则不能扩展成全文空段清洗。

## 9. 验收检查

### 有效格式

- 目标角色的最终字体、字号、对齐、缩进和间距符合已确认来源；
- 没有非语义直接格式覆盖；
- 中西文和复杂字符没有被错误统一；
- 表格边框、宽度和行高在 Word 保存后仍正确；
- 公式和高对象无裁切。

### 复合对象

- 成员数量、顺序和语言符合当前学校证据；
- 对象、题注、编号和引用目标均存在；
- 图片和表格没有因文字清理丢失；
- OMML、脚注、批注、书签和关系完整；
- 分页后对象成员没有不合理拆散；
- 未知对象得到原位保留或明确人工复核。

## 10. 未来开发预留

### FORMAT-01：有效格式观察

- 解析默认值、主题、样式链、直接格式、编号和容器属性；
- 按属性报告最终值、来源、覆盖和冲突；
- 只报告事实，不决定学校目标值。

### FORMAT-02：受控覆盖清理

- 仅删除已证明为非语义遗留的直接格式；
- 保护强调、变量、超链接、上标下标和学校特有格式；
- 以当前快照和目标对象为前置条件。

### COMPOSITE-01：复合对象识别

- 通过对象、字段、相邻关系和上下文识别图、表、公式和引用成员；
- 输出候选成员与不确定性；
- 不单凭“图”“表”等文本前缀作最终判断。

### COMPOSITE-02：对象闭包修改与验证

- 修改时携带对象、关系、书签和包部件；
- 检查成员顺序、关系可达和分页邻接；
- 不支持对象默认保留并提升人工复核。

如果未来两个主题的材料或实现分别超过一个清晰加载单元，将本文件拆为 `effective-format.md` 和 `composite-objects.md`。
