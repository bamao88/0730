# 母稿来源

本目录保存用于形成通用领域母稿的原始设计材料。来源材料可以包含尚未批准的架构想法、
配置形式和实现建议，因此它们不是正式 Knowledge，也不是现有产品能力说明。

## 当前来源

- [`论文模板树、内容树与确定性样式体系设计.md`](论文模板树、内容树与确定性样式体系设计.md)：
  三棵树、绑定层和确定性样式体系的原始设计稿；本轮只吸收内容树、模板树与绑定边界。
  其中“系统基础样式”、学校包覆盖和通用兜底链不进入当前母稿；样式只保留后续
  “样式观测与确定性补全合同”的问题边界。
- DocFit v3 历史内容字段/槽位契约：用于补齐语义字段与节点形态分离、复合对象和 unknown
  保留规则；不继承旧公共 Schema。
- DocFit v3 历史 ontology 与三份真实模板标准：用于交叉检查固定、填充、生成、说明、人工、
  未知等内容角色和伴随表单边界；学校字段、顺序和格式值不进入母稿。
- 当前正式 Knowledge v1 与长期文档：只用于校验“通用 Knowledge / 当前任务证据”边界。
- [`source-manifest.md`](source-manifest.md)：记录每项来源的原始位置、hash、使用方式和排除项。

母稿应吸收来源中的问题域、概念和属性维度，但不能因为来源写出了某个 YAML 结构，就把它
直接宣布为产品公共 Schema。历史资料只作为候选来源；发生冲突时，以当前 00–06 长期契约
和正式 Knowledge 边界为准。
