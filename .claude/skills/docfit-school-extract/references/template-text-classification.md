# 模板文字分类

根据文字在学校模板中的功能进行分类，不依据颜色、括号或占位符外观直接下结论。

| 类别 | 含义 | 提取结果 |
| --- | --- | --- |
| `fixed_content` | 学校要求保留的标题、声明或标签 | 记录原文和适用位置 |
| `conditional_content` | 仅在特定院系、学位、语言或材料类型下出现 | 记录文字和适用条件 |
| `slot_placeholder` | 等待当前任务数据填入的位置 | 记录槽位名称、位置和数据要求 |
| `format_instruction` | 指导填写、排版、删除或选择的说明 | 提取为操作规则，不当作固定文字 |
| `unknown` | 现有证据无法安全分类 | 保留原文并记录证据缺口 |

## 分类方法

1. 记录原文、对象引用、所在页面和相邻结构。
2. 检查书面要求或模板其他位置是否解释了它的用途。
3. 必要时查看页面，确认层级、颜色、边框和相邻槽位关系。
4. 输出分类、证据和适用条件。

## 常见误判

- 括号内容可能是必须保留的正式名称。
- 彩色文字可能是固定内容，而不是删除提示。
- 空下划线可能是签名区域，而不是普通槽位。
- 官方示例中的具体名称、题目和日期可能只是示例数据。
- 页眉、页脚、文本框和内容控件中的文字同样需要分类。
