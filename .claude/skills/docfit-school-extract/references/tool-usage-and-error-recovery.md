# Tool 使用与错误恢复

## `mcp__docfit__docx_inspect`

用于取得来源哈希、结构、对象引用和可检查范围。记录实际使用的 `document_ref`、`sha256` 和对象定位。引用失效或来源文件变化时，重新检查并使旧结论进入待复核状态。

## `mcp__docfit__docx_render`

只使用 `baseline` intent，不选择后端。在结构数据不能证明模板文字功能、页面分组、分页关系或视觉冲突时，建立当前来源的基线渲染。

## `mcp__docfit__docx_visual_review`

从已有 `render_ref` 读取最小相关页面；必要时包含相邻页或请求局部裁剪图。视觉结论必须绑定文档哈希、`render_ref`、页码和图像哈希。Tool 只返回图像，不替 Agent 判断通过或失败。

## Knowledge 选择

只读取当前判断需要的最小通用模块。记录文档 ID、包版本和内容摘要；不要把模块内容当作学校格式事实，也不要把当前学校结论写回 Knowledge。

## 失败恢复

| 失败 | 恢复动作 |
| --- | --- |
| 文件不受支持、路径未授权或输入无效 | 报告具体输入问题，不尝试其他工具绕过边界 |
| 文档引用或对象引用陈旧 | 重新调用 `mcp__docfit__docx_inspect`，重新绑定受影响结论 |
| 渲染页码超出范围或页面为空 | 根据最新检查结果缩小或修正页码，不猜测页面内容 |
| Knowledge 模块不可用 | 继续使用当前任务证据；缺少必要方法时说明能力缺口 |
| Tool 返回不完整证据 | 保留未知项，提出最小补证据动作 |

Tool 调用失败时，不发布虚构结果，也不把“已发起调用”写成“已获得证据”。
