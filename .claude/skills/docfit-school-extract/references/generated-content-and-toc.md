# 生成内容与目录

目录、题注和交叉引用由固定外壳、字段指令、来源对象、关系、结果样式与当前显示缓存共同组成。
可见缓存只是历史结果，不是内容真值。

## TOC 方法

1. 保留学校固定“目录”标题、真实 TOC 字段和学校展示的分级样式。
2. 先完成最终保留的固定标题、正文代表结构和可选区；不要用旧缓存反推尚未完成的语义。
3. 从最终标题树选择应进入目录的来源对象，并由你为每个来源指定 1–3 级。不要假设所有固定标题
   必须进入，也不要让代码通过标题词或编号正则代选。
4. 对真实 TOC 对象调用 `docx_edit` 的 `refresh_toc`，传入 target ref 和 Agent-selected
   `toc_entries`。Tool 负责维护 Word 字段、来源 outline level、缓存布局和更新标记。
5. 重新 inspect/render 目录，检查标题、缩进、点引导线、页码占位、颜色和下划线没有损坏。

若一级节标题和二级节标题共用一个 Word 样式，但学校通过编号、缩进或关系表达两级，仍可为它们
选择不同 TOC level。反之，样式名或 `1.1` 外观本身也不能脱离当前材料决定语义。

## 原生 Word 边界

LibreOffice 渲染适合风险扫描，但不能完全证明 Microsoft Word 更新域后的精确结果。交付证据应明确
这一边界；若任务环境能做 Word 原生复核，应更新目标 TOC 域、保存重开，再确认分级、引导线、
页码和字符样式稳定。不要用全局字段更新误伤声明、引用或其他域。

清理题注、书签、编号或交叉引用附近对象时，把可见文字与字段/关系边界分开看；只删除缓存文字
可能破坏机制，只保留缓存而丢掉来源也不算完成。
