# 完成与视觉复核边界

## 用途

本文件只说明边界：学校模板语义 Agent 不负责最终候选、渲染、页面复核或交付判断。
这些属于 Harness/App 的完成阶段。

## 触发条件

- 宿主反馈提到语义判断缺失、重复、冲突或不可消费。
- 宿主反馈提到物化、写入、渲染、验证或交付失败。
- Agent 准备把非语义问题写进 `semantic_judgments` 或 `needs_input`。

## 核心判断规则

- 如果宿主反馈说语义判断缺失、重复、冲突或不可消费，回到对应 `unit`、`reading_block` 或 `range_id`
  重判语义。
- 如果宿主反馈说物化、写入、渲染、验证或交付失败，不要补候选路径、渲染句柄、页码清单
  或验收说明；只有反馈暴露真实语义缺口时才修改 `semantic_judgments`。
- 如果当前学校语义确实无法判断，返回 `needs_input`，只说明缺少会改变语义处理结果的学校材料、
  Registry 字段、样式上下文、边界上下文或人工选择。

## 反例

- 宿主说写入失败时，Agent 改为返回候选路径、页码清单或验收说明。
- 宿主说物化失败时，Agent 为了让流程继续而伪造更细的范围或字段判断。
- 渲染或验证失败没有暴露学校语义缺口时，Agent 把它改写成 `needs_input` 问用户。

## 不负责事项

- 不定义发布工具、验证工具或 Harness 内部协议。
- 不要求 Agent 返回最终 Word、候选路径、底层身份、渲染句柄、页码清单或问题清单。
- 不把工具成功、渲染成功或验证失败当作学校语义结论。
