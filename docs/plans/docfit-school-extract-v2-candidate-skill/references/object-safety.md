# 对象与边界安全

## 结构边界

要删除的段落可能同时承载：

- `sectPr`、`pageBreakBefore` 或显式分页符；
- 书签、批注范围、字段边界、脚注/尾注引用；
- 图片或浮动对象锚点；
- Word 表格后必需的包装段。

这些是 Tool 的结构安全责任，不要求 Agent 手工迁移 OOXML。删除父对象和其子 run 时可一起提交；Tool 会把冗余子删除吸收进父操作，并返回 `absorbed_operations`。父对象要删除但子对象要物化或生成时属于真实语义冲突。

## 复合对象

- 图片单元可能包含图片、锚点、题注、编号和引用目标；
- 表格单元可能包含表题、表格、注释、来源和包装段；
- 公式单元可能包含 OMML、编号、制表位与相邻段落；
- 引用单元可能包含可见文字、字段/超链接、书签和目标条目。

只删除可见说明时选择最小对象。Tool 会保留已识别边界，并在不能安全闭合结构时失败；它不会为了满足删除请求静默破坏关系。

## 回执与复核

- `preserved_boundaries`：边界留在原位；
- `migrated_boundaries`：边界被安全迁移；
- `structural_risks`：需要 Agent 结合语义判断的非致命事实。

修改后检查相邻标题、分页、表格、题注、图片、字段和书签。`lastRenderedPageBreak` 只是历史渲染记录，不是稳定分页边界。
