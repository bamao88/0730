# 清理与可填写接口

## 何时读

只在当前区域或对象涉及说明/样例删除、封面值、摘要/正文/参考文献/致谢承载区、空白表单或
清理后不知道在哪里填写时读。不要因为任务是清理模板就在开始时默认读取。

## 判断原则

干净模板不是“字越少越好”，而是：固定结构仍在，学校职责仍在，样例实例已移除，填写和生成接口清晰可用。

对当前对象先分类：

- 学校名、声明、表单标签、固定标题：保留固定内容；
- 题名、作者、学号、摘要正文、关键词等任务值：替换为填写槽；
- 目录、题注编号和交叉引用：保留生成机制，不保留旧缓存为内容真值；
- 可选成果页、可选附录、实名页：把“是否出现”与“出现后由谁填写”分开；
- 教程、样例、格式说明和演示内容：将其有用职责迁移到槽位/容器后删除。

## 先迁移职责，再删除样例

说明和样例可能同时展示内容类型、语言、数量、格式、页面容器和条件规则。删除前先确认这些职责已经有去处。

对学生实际要填写的内容区，采用“一个格式代表物化为槽 + 其余样例批量删除”。如果删除后只留下标题、空白页或空表格，
却没有唯一可填写目标，这个区域尚未完成。

## 选择最小安全对象

- 标签和值在同段：保留标签 run，只物化值 run；
- 固定标题和蓝/红色字号说明在同段：保留标题 run，删除说明 run；
- 一整段都是说明：删除 paragraph；
- 边框、行高、单元格或段落样式必须留下：清空内容或物化内层 run；
- 空单元格、签字区、空下划线：可能本身就是学校容器，不按“无文本”删除。

## 内容形态

- 标量：题名、作者、学号、日期。边界小，不覆盖固定前后缀。
- 段落流：摘要、正文、致谢、参考文献。至少留下一个能承载可变长度内容的槽。
- 复合内容：图、表、公式、双语题注。不要将整组压成单个字符串槽；当前 Tool 无法安全表达时原位保留。

## 常用规范字段 ID（只在当前对象确实承担该职责时使用）

- 中文题名 `thesis.title.zh`；英文题名 `thesis.title.en`；
- 中文作者 `author.name.zh`；学号 `author.student_id`；院系 `author.department`；专业 `author.major`；
- 中文导师 `advisor.name.zh`；导师职称 `advisor.title`；
- 中文摘要 `abstract.zh`、中文关键词 `keywords.zh`；英文摘要 `abstract.en`、英文关键词 `keywords.en`；
- 正文承载区 `body.chapters`；参考文献条目 `references.entries`；致谢正文 `acknowledgement.body`；
- 附录标题 `appendix.title`、附录正文 `appendix.body`。

已知上面的准确 ID 时直接批量 lookup；不知道时针对一个对象用一个具体中文概念搜索，例如“中文论文题目”或
“导师职称”。不要用 `cover fields list all` 一类宽泛查询。若精确 ID 少写了语言或层级后缀，Registry 会在同一
批次返回 `operation=suggest` 的候选，不会让整个批次失败。

## 占位与颜色

- 可见占位只使用 `【字段标签】` 区分，不添加灰色、底纹或 Word 占位状态；填写后整体替换括号内容。
- 红、蓝等颜色先作为当前对象的语义证据：它可能表示填写区、删除说明，也可能是学校正式强调色。
- 判断某对象应成为槽但其直接颜色只服务于样例展示时，在物化操作上提交
  `clear_direct_format: ["color"]`。Tool 只移除直接颜色，不改学校的字体、字号、间距和容器。
- 固定内容的颜色不再需要时用 `normalize_format`；颜色有正式含义时保留。不要做全文颜色清洗。

## 改完后看什么

- 学校固定文字和容器没有误伤；
- 样例和教程没有残留；
- 每个学生内容职责都有可见、唯一、有边界的填写槽；
- 占位文字没有吞掉标签、年月日等固定文字；
- 删除后没有孤立标题、无职责空白页或空容器。
