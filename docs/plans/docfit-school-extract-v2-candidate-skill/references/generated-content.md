# 目录与其他生成内容

## 何时读

只在当前对象涉及目录/图目录/表目录、点引导线、页码、题注编号、书签、交叉引用，或 Word 字段的当前显示文字时读。

## 核心模型

生成对象由以下职责组成：

- 学校固定外壳（例如“目  录”标题、位置和页面样式）；
- 字段指令或生成规则；
- 生成所依赖的标题、题注或目标对象；
- 当前显示缓存；
- 结果段落样式和内部关系。

可见缓存只是一次历史生成结果，不是可复用的内容真值。

## 目录清理

1. 保留“目  录”等固定外壳和目录段落样式。
2. 保留真实 TOC 字段的 begin/instruction/separate/end 边界。
3. 对 separate 之后、end 之前的结果段落使用 `clear_content`；Tool 会删除纯缓存结果段落，并在字段
   边界所在段落中保留指令、清除可见文字和点引导线。
4. 批量清除样例章名、`XXX`、`XX`、旧页码和“此项非必需项”等缓存文字。
5. 检查新图：目录标题、页面和结果段落骨架仍在，旧条目不再可见。

不要把目录转成静态文字，不要因为当前条目“看起来像结构”就保留它们，也不要整段删除承载字段边界的对象。

## 样式和验证限制

旧目录缓存可能用 run 直接格式暂时遮住错误的 `TOC 1/2/3` 样式。当前 Tool 能安全清理可见缓存，但不会替 Agent 重建或证明
Microsoft Word 中的 TOC 结果样式。

因此：

- 本任务中先保留域机制并清理明确错误的缓存；
- 不用 LibreOffice 截图宣称 Word 原生更新后的字重、缩进、点引导线和页码已得到证明；
- 当当前修改仅涉及缓存清理时，不自行扩大为全文字段更新。

## 题注、编号和交叉引用

当前清理目标若与图、表、公式、书签或内部链接共存，先读取 `boundaries-and-object-safety.md`。不把学生稿或样例中的可见编号直接当成生成规则，
也不在只看到文字时删除其书签、字段或关系目标。

## 修改后看什么

- 固定标题与生成字段仍存在；
- 旧缓存不再污染最终模板；
- 清理没有孤立字段边界、书签或超链接；
- 只回看当前修改区域，不为了覆盖率进行全文逐页复核。
