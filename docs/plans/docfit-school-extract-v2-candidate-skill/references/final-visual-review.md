# 最终全页视觉检查

本卡只供“最终视觉检查”角色使用。局部语义判断不得为了覆盖率读取整篇页面。

## 判定单位

应用给出的每张图片都是最终候选 Word 的原生全页 PNG。按原始分辨率查看每一页，并为每个绑定
页码返回一个明确结论：

- `clean`：没有发现下列可见缺陷，`defects` 必须为空；
- `defect`：至少有一项可见缺陷，逐项说明类别、现象和修复目标。

不能因为渲染成功、页面数量正确、文本可提取、Office 校验通过或其他页面正常而判定当前页
`clean`。图片返回只证明证据可用，不证明证据已经检查。

## 必查缺陷

- 文字、图片、公式或内容控件被裁切、重叠、缺失或替换为错误字形；
- 表格断裂、越界、列宽异常，图片与题注错位；
- 段落、标题或控件间距明显漂移，出现异常空白或孤立标题；
- 页面重复、缺失或分页位置异常；
- 页眉、页脚、页码、节边界、目录或跨页元素错位；
- 写作说明、学生样例、旧目录缓存、占位残片或其他不应交付的可见残留。

最终检查不重新判断某个字段应叫什么、某段是否属于学生内容，也不根据全篇画面改写模板语义。
如果可见问题需要编辑，描述可定位的视觉现象；应用会把它转换为单页有界修复任务。

## 环境失败

如果没有收到可读取的 PNG，或图片损坏、为空、与页码不匹配，不得给出 `clean`。返回具体证据
问题，由应用处理渲染环境或重试。不得拿旧版本图片或局部裁剪图补足最终页面结论。
