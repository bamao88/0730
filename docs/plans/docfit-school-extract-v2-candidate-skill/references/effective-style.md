# 有效样式

## 为什么直接 XML 不够

Word 的可见结果可能依次来自文档默认值、段落样式链、段落样式、字符样式、段落直接 run 属性、run 直接属性和主题。删除目标中的直接 `w:color` 后，`Hyperlink` 等字符样式仍可能提供蓝色和下划线。

`format` 中的 `effective.color`、`effective.underline` 及其 `.src` 才是当前回读事实。来源可以变化，目标结果不能只靠来源层猜测。

## 决策与执行边界

- Agent 判断颜色或下划线是学校正式样式、填写提示、说明色还是样例色。
- 需要改变时，提交期望结果，而不是指定删除哪层 XML：

  ```json
  {"format": {"color": "black", "underline": "none"}}
  ```

- Tool 在最小可行范围写入覆盖、处理样式继承，并在新版本回读有效值及来源。
- 返回仍为蓝色/下划线时，操作不能作为成功提交。

不要做全文颜色清洗。相同颜色在不同对象上可能承担不同语义；每次只对已判断的当前对象或生成复合对象提交结果。

## 复核

- 查看 `effective_format_changes.before/after`，而不只看 XML 是否少了属性。
- 物化槽后确认占位、字体、字号、间距和填写线没有因覆盖而丢失。
- 对会在 Word 中重新生成的字段，再按[生成内容](generated-content.md)执行原生更新验证。
