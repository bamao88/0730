# 页面边界与复合对象安全

## 何时读

只在以下情况读：删除后出现空白页/断页异常；对象靠近分页符、分节符或表格末尾；目标段落含图片、公式、书签、批注、脚注、题注或浮动对象；
删除可选页或整个条件区。

## 语义区域不等于物理页

一个学生内容区可以跨多页，多个区域也可以共用一页。自然换页、标题词语、普通空段和 `lastRenderedPageBreak` 都不能单独证明应删整页或切分区域。

边界附近的空段可能：

- 承载分页/分节、字段、书签、批注、修订或对象锚点；
- 是 Word 表格后必需的包装段；
- 完成上一页布局或形成下一页顶部留白；
- 才是没有职责的偶然空段。

不在仅有页面截图时删除边界空段。优先处理明确可见内容；边界职责不明时原位保留。

## 复合对象不是相互独立的文本

- 图片单元：图片、锚点、题注、编号和引用目标；
- 表格单元：表题、表格、注释、来源和包装段；
- 公式单元：OMML、编号、制表位/对齐和相邻段落；
- 引用单元：可见文字、字段/超链接、书签和目标条目；
- 条件表单：固定标题、字段、签字区、分节和分页。

要删除的文字和 Drawing/字段/书签在同一段时，不删整段。当前 Tool 无法安全拆分或迁移复合成员时，原位保留并继续处理其他确定对象。

## 条件页和可选区域

只删可见文字可能留下空白分节页。当学校证据明确整个条件为不出现时，缺席策略应同时考虑内容容器、分节边界、`oddPage/evenPage` 和后续页眉页脚。

当前只能确认“学生可选填写”而不能确认“本模板应删除”时，保留标题并留下可见填写槽，不自行删整页。

## 修改后看什么

- 受保护的图、表、公式、字段和学校表单仍在；
- 相邻标题、题注和容器没有被误伤；
- 页数或当前页布局变化与所做删除相符；
- 没有因为重复边界产生纯空白首/末页；
- 表格结构、行高、合并和包装段没有异常。
