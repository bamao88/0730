# 准备论文转换模板

## 输入

- 学校论文模板 DOCX；
- 配套的学校要求；
- 可选的官方示例或用户补充说明。

来源文件保持不变。所有清理都在新的模板副本上完成。

## 输出

只交付两个产物：

1. 冻结干净模板 DOCX；
2. 绑定该模板的槽位索引。

槽位索引说明后续论文转换可以在哪里填写什么，并包含需要保留的固定区域、只能人工
处理的区域和未解决项。检查结果写入槽位索引，不额外交付证据报告或验证文件。

## 任务

1. 阅读学校模板与配套要求，了解模板包含哪些论文部分。
2. 检查整份模板的内容、结构和页面效果。
3. 保留学校固定内容与版式；清除用于指导填写的说明和示例内容。
4. 把后续需要填写或替换的位置整理成槽位。签名、盖章等不能自动填写的位置保留为
   人工区域。
5. 按论文部件处理目录、封面、声明、页眉页脚、分节等特殊结构。
6. 检查清理后的完整模板，生成与最终模板绑定的槽位索引，并交付两个产物。

## 规则

- 不把学生论文内容写入模板。
- 不创建学校 profile、学校 Knowledge 或跨任务学校包。
- 学校模板和要求没有规定的格式，不根据经验补造。
- 说明文字和示例内容可以清理，但不要破坏承载它们的表格、段落、分节或页面版式。
- 无法确认用途的内容先保留，并在槽位索引中标明未解决状态。
- 目录不是普通文本槽位；封面、声明、签章区、页眉页脚和分节也按各自结构处理。
- 只交付通过程序验证的最终模板及其槽位索引。

## 特殊论文部件

references 按论文部件组织，不对应处理阶段。先查看
`.claude/skills/docfit-school-extract/references/index.md`，只读取当前模板实际包含的特殊
部件说明。

## 最终回复

给出干净模板和槽位索引的位置，并简要说明模板中仍需人工处理或用户确认的内容。
