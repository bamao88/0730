# 模板分析与槽位设计

当模板结构复杂、内容分类困难或需要设计自动槽位时读取本文。

## 观察覆盖

结构观察至少考虑：

- 节和页面设置、分节边界、页眉页脚及继承；
- 段落、表格、合并单元格、列表和编号；
- 图片、形状、文本框、内容控件、书签和域；
- 命名样式、直接格式、继承后的有效值；
- 隐藏文字、空段落、空单元格和只用于维持几何的对象。

视觉观察覆盖全部页面，并放大检查缩略图中无法辨认的标签、占位符、域结果、边界和
小字。结构告诉你对象是什么，页面告诉你它最终造成什么结果；二者不能互相替代。

## 模板地图

按逻辑页面或区域记录：用途、首尾锚点、结构容器、可见内容、固定边界、候选槽位、
条件和未决对象。模板地图是分析产物，不是新的稳定 runtime schema。

## 设计槽位

一个自动槽位应同时满足：

1. 语义用途明确，例如“封面作者姓名”，而不是“第二个空格”；
2. 最终快照中的目标唯一；
3. 可接受内容类型和数量明确；
4. 写入不会越过 fixed 边界或破坏布局容器；
5. 当前 Tool 能观察、定位并验证它。

定位信号可以组合对象引用、结构路径、前后邻接语义、容器身份和预期指纹。至少两个
独立信号应共同缩小到一个目标。页码和 bbox 只描述某次 render 中的观察位置。

## 什么时候不要创建自动槽位

- 多个候选无法区分；
- 内容需要签名、盖章、手写或复杂人工排版；
- 是否存在取决于未确认条件；
- Tool 不能稳定观察文本框、形状或其他承载对象；
- 写入边界可能覆盖学校固定内容；
- 只能靠文件名、颜色或常见学校格式推测用途。

这些情况分别保留为 manual、conditional、unresolved 或 gap，不要用宽松 locator 掩盖。
