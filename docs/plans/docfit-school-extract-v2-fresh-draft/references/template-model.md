# 模板接口模型

学校模板不是若干待替换文字的集合，而是一份承载论文结构、内容责任、生成行为和版式
关系的文档接口。整理模板时应保留它能够做什么，而不是保留源文件碰巧展示了什么。

## 四个互相独立的视角

| 视角 | 回答的问题 |
|---|---|
| 结构 | 模板有哪些逻辑区域、容器、顺序和跨区域关系 |
| 责任 | 一项内容由学校固定、后续填充、系统生成、重复、按条件出现还是人工完成 |
| 行为 | 空内容怎样处理，字段怎样更新，编号和引用怎样保持关系 |
| 呈现 | 当前学校材料明确了哪些最终有效格式和页面关系 |

不要用其中一个视角替代另一个。相同外观的两段文字可能分别是固定标签和示例值；相同
标题样式的两个区域可能分别是正文内部标题和独立学校表单；同一逻辑单元也可能跨越多页。

## 从来源表达转成模板责任

源材料常用说明文字、示例值、空白线、表格、内容控件、字段结果或完整示例章节表达
要求。它们只是表达方式，不是最终接口。

- 固定学校文字和结构直接进入模板骨架。
- 示例值证明这里需要承接某类内容，建立对应填写接口后再移除示例值。
- 说明文字先拆出仍然有效的结构、格式、顺序、适用条件和人工要求，再决定文字本身
  是否进入成稿。
- 字段缓存和示例编号用于观察生成结果，但最终保留的是可更新的机制及其有效样式。
- 同构示例用于证明一种可重复能力；只有页面方向、栏数、页眉页脚、表单职责或其他
  真实结构不同，才保留为独立变体。
- 无法可靠解释的来源对象保持原样并进入未决，而不是硬套到最接近的已知类型。

## 填写接口的粒度

填写位置不是“某个地方是空的”，而是下游可以稳定消费的一项责任：

- 标量适合题名、姓名、日期等单值事实；
- 段落流适合可变长度的连续文字；
- 复合内容适合保持段落、表格、图片、公式和题注等有序结构；
- 重复区域承接数量不固定的同构内容；
- 生成区域由标题、题注或其他内容关系产生，不接收静态结果；
- 人工区域可以定位和保留，但不承诺自动填入；
- 条件区域同时记录区域和适用条件；
- 未决区域记录当前能力或材料无法安全表达的部分。

一个视觉区域可以包含多个接口。例如，表单可能由固定标签、数个标量槽位、一项条件
说明和一个人工签章区组成。不要为了“一个区域一个槽位”而压扁结构。

## 逻辑单元和物理载体

逻辑单元由内容所有权和模板职责决定，不由页数或标题数量决定。正文中的多个章节可以
属于一个可重复正文容器；一份学校行政表单即使与其他内容共页，也可以是独立逻辑单元。

页、段落、表格、文本框或内容控件只是物理载体。整理时保留逻辑单元的完整职责，同时
允许载体在不损失行为的前提下被规范化。不能先按物理页切开，再反推每页是什么。

## 槽位索引表达什么

槽位索引是冻结模板的消费接口，不是第二份学校知识库。它应足以让下游知道：

- 哪些区域属于不可随意修改的固定骨架；
- 每个可自动处理接口承接什么内容形态和数量；
- 哪些区域由内容关系生成或按实例重复；
- 哪些区域需要人工、受条件控制或仍未解决；
- 这些结论适用于哪一份冻结模板。

索引只保存当前任务需要的学校差异，不把学校事实、模板或参数提升为跨任务 Knowledge。
