# 冻结模板产物合同

只有在准备、检查或发布最终产物时读取本文。它定义语义内容，不提前锁定 JSON 字段名
或目录布局。

## 一个完整产物包含什么

- 一份可独立打开且不再继续修改的干净模板 DOCX；
- 该 DOCX 的精确 SHA-256，以及来源模板的 SHA-256；
- 当前任务使用过的来源及其身份、适用范围和证据引用；
- 固定区域及其最终快照 locator/指纹；
- 自动槽位、manual 区域、gap、冲突和未决项；
- 绑定最终 hash 的全页视觉检查和确定性验证结果。

所有引用只在当前任务和指定模板 hash 内有效。产物不是学校注册表、Knowledge 条目或
全局 Artifact 系统。

## 自动槽位至少表达什么

- `slot_id`：只在当前冻结快照内稳定的语义标识；
- locator：能在该快照中唯一解析的定位信息；
- expected content：标量、段落流、复合内容或其他受支持类型；
- cardinality：允许为空、必须一个、允许多个等数量约束；
- fixed boundary：写入不能越过的学校固定内容边界；
- evidence：支持槽位身份、用途和范围的当前任务证据。

页码、bbox、颜色和单次近似文字命中可以协助观察，但不能单独承担 locator。

## manual、gap 与 unresolved

- `manual` 表示区域存在且用途明确，但签名、盖章、手写或能力边界使其不能自动填写。
- `gap` 表示当前 Tool 或产物模型无法安全观察、定位、表达或验证该区域。
- `unresolved` 表示材料之间存在未裁决冲突，或缺少会改变模板语义的用户信息。

不要用空自动槽位代替这三类状态。

## 冻结不变量

最后一次模板写入之后，重新 inspect、取最终 hash、建立 locator、完成视觉检查和验证。
如果模板再次变化，旧索引、固定区域指纹、视觉证据和验证结果全部失效。

只有应用壳或 Tool 已验证下面的机器事实时才能发布：

- package 文件齐全且路径在当前任务授权范围内；
- manifest 绑定实际模板 hash；
- 每个自动槽位零歧义地解析一次；
- fixed 区域满足保护合同；
- review/validation 都对应同一最终 hash；
- 失败时没有发布部分产物。
