# 复杂模板情况

只有遇到相应结构时读取本文。

## 重复占位文字

相同文字可能分别属于封面、声明、审批表或页眉。用容器、相邻标签、逻辑页面和对象
指纹区分；不能区分时不编辑，也不创建自动槽位。

## 彩色、括号或下划线文字

外观只能提示“值得检查”，不能证明是说明或示例。先确认功能，再决定移除文字、保留
格式容器还是整体保留。

## 文本框、形状和内容控件

可见内容不一定在普通段落流中。确认 Tool 是否能稳定观察、定位和验证该对象；不能时
保留并记录 gap，不能通过附近段落近似定位。

## 合并单元格与表单空壳

清空示例值时保留必要的单元格合并、尺寸、边框和标签。删除一行或一表格前，确认它不
承担学校固定表单和分页职责。

## 签名、盖章和日期

学校标签和表单外壳通常是 fixed；实际签名、盖章、手写日期或需人工确认的区域是
manual。不要把“无法自动填写”解释成“整块可以删除”。

## 条件页面

确认条件之前保留页面及其结构，并记录 conditional/unresolved。只有来源明确说明条件
不成立时，才考虑移除；缺少学生内容不属于模板提取阶段的删除依据。

## 页眉页脚、域和分页边界

修改正文可能改变页数、节继承或域结果。清理后检查每一节的首尾页面和关键域；不要把
某次 render 的页码视为跨快照稳定事实。

## 模板中混入学生论文

停止填充行为，把学生文件留作不在本 Skill 范围内的输入。冻结模板不得包含学生正文、
个人信息或从学生论文复制来的内容。
