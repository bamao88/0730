# 来源和内容决定

当来源身份、适用范围、优先关系或内容功能存在歧义时读取本文。

## 先描述来源，而不是先排固定名次

为每份材料记录：谁发布、面向谁、何时适用、是否完整、它在声明要求还是展示实例。
不要假定“Word 一定高于 PDF”或“新文件名一定更新”。来源强弱取决于权威性、适用性、
明确程度和是否直接针对当前模板。

用户确认可以解决当前任务中的歧义，但要记录确认内容和适用范围；它不会把学校事实
提升为产品 Knowledge。

## 冲突处理

先判断冲突属于哪一类：

- 实际冲突：两份适用来源对同一目标提出不同要求；
- 范围不同：本科/研究生、论文类型或年份不同；
- 表达层不同：书面要求给目标，模板示例展示实现；
- 观察差异：命名样式与可见直接格式不同；
- 能力差异：当前 Tool 看不到或无法验证某种对象。

能够用适用范围消解时，记录理由。不能消解且会改变模板时，保留两个结论并询问；不要
静默选择更方便实现的那一份。

## 判断可见内容的功能

综合观察以下信号：

- 来源是否明确称它为说明、示例、必填项、固定声明或可删除项；
- 它所在的结构是否承担学校表单或版式职责；
- 相邻标签、重复模式和逻辑页面用途是否支持同一解释；
- 删除文字后，容器、间距、分页或填写语义是否仍完整；
- 是否存在同样文字但不同用途的多个候选。

只有颜色、括号、占位符样式或常见模板经验时，分类强度不足以支持删除。

## 决定结果

- 证据明确且目标唯一：按 fixed、slot、guidance/example、conditional 或 manual 处理。
- 功能明确但自动能力不足：标 manual 或 gap。
- 来源冲突且没有裁决依据：标 unresolved，必要时询问。
- 功能不清：保留原状并标 unknown；不要先删后问。
