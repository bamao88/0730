# 可选只读委派

只有主 Agent 决定把局部分析交给 `docfit-unit-analyst` 时读取本文。委派不是必经步骤，
也不按封面、目录、正文等类型建立固定专家。

## 适合委派的工作

- 一组边界明确、证据量大的页面或结构；
- 需要独立核对的来源冲突；
- 文本框、复杂表格、页眉页脚等局部结构盘点；
- 修改前后的局部视觉差异说明。

简单任务、跨全文合并决定、编辑、渲染、验证和用户询问由主 Agent 完成。

## 任务包

明确提供：

- 一个具体问题和成功条件；
- 授权的文件、hash、对象/页面范围和 evidence refs；
- 当前已经确认的来源身份与结论；
- 本次真正需要的通用 Knowledge 内容和版本/digest；
- 必须排除的范围；
- 返回格式：观察事实、证据、解释、冲突、unknown 和建议下一步。

不要让 Subagent 自行遍历项目、加载 Skill 或猜测缺失 Knowledge。

## 合并返回

Subagent 的结果是 finding，不是最终决定。主 Agent 检查证据是否仍绑定当前快照，合并
跨区域关系，解决重复或矛盾 finding，并独自负责是否编辑、是否询问以及能否冻结。
